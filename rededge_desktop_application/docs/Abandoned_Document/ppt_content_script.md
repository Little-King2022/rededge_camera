# RedEdge Monitor 软件功能介绍 PPT内容脚本

## 幻灯片1：封面
标题：RedEdge Monitor 软件功能介绍
副标题：RedEdge-M 多光谱相机桌面控制应用
底部：专业多光谱遥感监测解决方案

## 幻灯片2：产品概述
产品定位：
- 基于 Electron + Vue3 的桌面应用程序
- 专为 RedEdge-M 多光谱相机设计
- 提供远程控制、实时预览、数据管理和图像处理功能

主要用途：
- 农田遥感监测
- 农作物健康评估
- 多光谱数据采集与分析

技术特点：
- Main-Renderer 双进程架构
- 本地 SQLite 数据持久化
- 4G 路由器 + FRP 内网穿透远程访问支持

## 幻灯片3：功能模块总览
九大核心功能模块：
1. 连接管理 - 多相机配置与连接
2. 实时预览 - 实时画面监控
3. 拍照控制 - 手动与定时拍摄
4. 状态监控 - 系统状态实时显示
5. 文件管理 - 文件浏览与下载
6. 辐射定标 - 辐射校正处理
7. 图像配准 - 多波段对齐处理
8. 数据分析 - 影像分析工具
9. 应用设置 - 个性化配置

## 幻灯片4：连接管理页面
核心功能说明：
- 管理 RedEdge-M 相机的多个连接配置
- 支持 HTTP/HTTPS 协议
- 记录连接历史和状态

主要操作按钮：
- 添加 Profile（协议、Host、Port、路径前缀）
- 编辑配置
- 测试连接
- 激活/切换相机
- 删除配置

使用场景描述：
- 田间作业前配置相机连接
- 多地块多相机管理
- 连接异常时排查调试

## 幻灯片5：实时预览页面
核心功能说明：
- 获取相机实时预览画面
- 两步拉取机制确保数据完整性
- 可配置刷新频率

主要操作按钮：
- 开始预览 / 停止预览
- 刷新频率调节（默认1Hz）
- 查看帧时间戳和状态统计

实时统计信息：
- 当前帧时间戳
- 最近成功时间
- 连续失败次数
- 当前刷新频率
- 帧数据大小

使用场景描述：
- 作业前确认相机视角
- 实时监控拍摄画面
- 检查构图和覆盖范围

## 幻灯片6：拍照控制页面
核心功能说明：
- 手动触发单次拍照
- 相机端定时连续拍摄
- 拍照历史记录管理

主要操作按钮：
- 立即拍照
- 启动定时拍照（设置间隔）
- 停止定时拍照
- 查看拍照历史

功能特点：
- 调用 /capture API 实现拍照
- 通过 /config 和 /timer 实现定时控制
- 能力探测确保功能兼容性

使用场景描述：
- 单次拍摄关键画面
- 设置定时任务自动采集
- 周期性监测作物生长

## 幻灯片7：状态监控页面
核心功能说明：
- 实时展示相机各项系统状态
- 周期性自动刷新（默认2秒）
- 丰富的状态指标显示

监控指标：
- Storage（SD卡状态、容量、类型）
- GPS 卫星（已使用/可见数量）
- DLS 状态（下投光传感器）
- 时间信息（UTC、GPS时间、时间源）
- 位置信息（纬度、经度、精度）
- 高度信息（MSL/AGL）
- 速度与航向
- 拍照配置与电压

使用场景描述：
- 作业前系统检查
- 异常状态快速定位
- GPS信号质量监控

## 幻灯片8：文件管理页面
核心功能说明：
- 浏览相机存储卡文件
- 文件下载到本地
- 文件删除与SD卡格式化

主要操作按钮：
- 浏览目录（面包屑导航）
- 多选文件
- 加入下载队列
- 删除文件
- 格式化SD卡（需强确认）

下载队列功能：
- 状态展示（pending/downloading/completed/failed/paused）
- 进度显示（字节数、百分比）
- 暂停、恢复、重试操作
- 持久化存储

使用场景描述：
- 作业完成后数据下载
- 存储空间清理
- 重要数据备份

## 幻灯片9：辐射定标页面
核心功能说明：
- 辐射定标板检测与识别
- QR码序列号解析
- 辐照度计算与记录

主要操作按钮：
- 选择定标板图像
- 扫描QR码
- 计算辐照度
- 保存定标记录
- 查看历史记录

功能特点：
- 支持5波段定标板
- 自动检测定标板区域
- 精确计算各波段反射率

使用场景描述：
- 每次作业前定标
- 校正光照变化影响
- 确保数据可比性

## 幻灯片10：图像配准页面
核心功能说明：

- 批量配准输出

主要操作按钮：

- 查看处理进度

- 保存配准结果

## 幻灯片13：功能流程图
用户操作流程：
1. 连接配置 → 连接相机
2. 预览确认 → 调整视角
3. 设置参数 → 开始采集
4. 状态监控 → 异常处理
5. 数据下载 → 本地存储
6. 定标配准 → 数据处理
7. 分析应用 → 结果输出

模块关联：
- 连接管理是所有功能的基础
- 预览与拍照共享相机连接
- 文件管理与下载队列联动
- 定标与配准为数据处理提供支持

## 幻灯片14：典型使用场景 - 日常作业采集
场景描述：农田日常监测作业流程

作业流程：
1. 打开应用 → 连接相机
2. 实时预览 → 确认视角
3. 配置定时 → 开始采集
4. 状态监控 → 确保正常
5. 采集完成 → 下载数据
6. 格式化SD → 准备下次

关键节点：
- 预览确认避免无效采集
- 状态监控及时发现问题
- 定期下载防止存储溢出

## 幻灯片15：典型使用场景 - 数据处理流程
场景描述：采集数据后期处理流程

处理流程：
1. 数据下载 → 本地存储
2. 辐射定标 → 校正光照
3. 图像配准 → 波段对齐
4. 数据分析 → 信息提取
5. 结果导出 → 报告生成

关键节点：
- 定标确保数据可比性
- 配准保证波段精确对齐
- 分析生成有价值信息
