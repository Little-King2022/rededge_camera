# Camera Band Images

Please place your camera band visualization images here:

1. **spectral-response.png** - Spectral response curves for all camera bands
2. **band-configuration.png** - Band configuration diagram

These images will be displayed when users click on the "Camera Band Information" card in the Status view.

## Image Requirements

- Format: PNG, JPG, or JPEG
- Recommended width: 400-600px
- Both images should have similar heights for best visual effect
- Images should clearly show the spectral characteristics of the camera bands
